# PROJECT_01_FOODMENU-APP

A Django web application for managing food menus, categories, and user accounts. This project allows users to register, login, and manage food items efficiently.

---

## 📝 Features

- **User Management**
  - User registration, login, logout
  - Profile management

- **Food Item Management**
  - Add, update, delete, and view food items
  - Categories for food items
  - Availability and status tracking

- **Caching**
  - Cached views for faster performance
  - Reduced database load

- **Admin Panel**
  - Manage users and food items
  - View logs and system activity

---

## ⚙️ Tech Stack

- **Backend:** Python, Django
- **Database:** Postgres
- **Frontend:** Django Templates (HTML/CSS)
- **Version Control:** Git & GitHub
